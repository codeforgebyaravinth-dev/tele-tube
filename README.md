# TeleTube 🎬
### Premium Glassmorphic YouTube Clone

TeleTube is a high-fidelity video-sharing platform built with **Next.js 14**, **Tailwind CSS**, and **Appwrite**. It features a unique "GlassTube" design system with deep glassmorphism and an ultra-dark aesthetic.

## 🚀 Features
- **Modern UI:** Premium dark mode with glassmorphic elements.
- **Video Feed:** Responsive grid with custom video cards.
- **Watch Page:** Integrated player with engagement features.
- **Creative Studio:** Upload dashboard with progress tracking.
- **Authentication:** Secure login and signup flows.

## 🛠️ Tech Stack
- **Framework:** Next.js 14 (App Router)
- **Styling:** Tailwind CSS + Framer Motion
- **Backend:** Appwrite (Auth, Database, Storage)
- **Icons:** Lucide React

## 📦 Installation
```bash
npm install
npm run dev -- -p 3001
```
